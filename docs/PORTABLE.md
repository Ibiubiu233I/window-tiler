# 铺窗 · Window Tiler

Windows 10 22H2 / Windows 11 x64 免安装窗口平铺工具，自带 .NET 运行时。

1. 将压缩包完整解压到固定文件夹，双击 `WindowTiler.exe`。
2. 勾选已打开的窗口，选择目标显示器、平铺区域和布局。
3. 检查预览后点击平铺；可点击“恢复上次位置”撤销最近一次平铺。

关闭主窗口默认驻留托盘。双击托盘图标打开面板，右键菜单可以退出。替换新版程序前请先退出旧版。

设置保存在 `%LOCALAPPDATA%\WindowTiler\settings.json`。移动或替换 EXE 不会清除设置。

快捷键：`Ctrl+Alt+Space` 打开面板，`Ctrl+Alt+Enter` 平铺，`Ctrl+Alt+Backspace` 恢复位置。

程序尚未签名。部分游戏、尺寸受限或以管理员权限运行的程序可能无法调整，具体结果会显示在窗口列表中。
