铺窗的首个 GitHub 正式发布版本，提供 Windows x64 免安装程序。

## 下载与运行

- **WindowTiler-0.5.3.exe**：直接下载并双击运行，自带 .NET 运行时，无需安装。
- **WindowTiler-0.5.3-win-x64.zip**：便携包，包含程序、使用说明及 Apache 2.0 许可证；解压后运行 `WindowTiler.exe`。
- **SHA256SUMS.txt**：EXE 和 ZIP 的 SHA-256 校验值。

适用于 Windows 10 22H2 / Windows 11 x64。GitHub 自动提供的 Source code 文件是源码归档，运行程序请选择上面的 EXE 或 ZIP。

## 主要功能

- 选择已打开窗口并平铺到指定显示器，支持多显示器独立分组。
- 自动网格、横向、纵向、主次布局及可保存的自定义分区模板。
- 全屏或划定区域平铺，支持屏幕框选、像素微调和多个区域方案。
- 拖拽布局预览交换窗口位置；固定内容比例的窗口可整组靠拢居中。
- 最大化、最小化窗口先恢复普通状态再平铺，支持恢复上次位置。
- 平铺后按列表顺序整组前置；并发调整窗口，减少重复移动与等待。
- 默认浅色，支持深色及跟随系统；托盘、全局快捷键和登录后启动设置。

v0.5.3 的界面采用更高的主窗口；“全屏”区域下拉框占满整行，“划定区域”与方案选择并排显示。区域编辑器通过不同背景色、边框、尺寸和面积占比区分总范围与选区。

## 更新及使用提示

更新前先从托盘菜单退出旧版，再运行新程序。已有设置保存在 `%LOCALAPPDATA%\WindowTiler\settings.json`，替换程序不会清除设置。首次运行后需手动勾选要平铺的窗口。

默认快捷键：`Ctrl+Alt+Space` 打开面板，`Ctrl+Alt+Enter` 平铺，`Ctrl+Alt+Backspace` 恢复位置。

## 验证与已知限制

- 发布构建运行布局、比例、整组靠拢与区域计算测试；本版本此前已在双 1080p 显示器上通过专用窗口回归和界面检查。云端发布流程不运行交互式桌面回归。
- 程序未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。
- 部分游戏、固定尺寸或高权限窗口可能拒绝外部调整；不保证所有第三方窗口都能严格匹配布局。阴阳师客户端尚未实测。
- 平铺后的前置不等于永久置顶；之后仍可正常切换其他程序。
- 不同 DPI、显示器热插拔和干净系统首次运行等场景仍需进一步验证。
- 本版本提供窗口管理功能，不含自动点击或游戏脚本功能。
