# 铺窗 · Window Tiler

一个面向 Windows 的窗口平铺工具：选择已经打开的窗口，为它们分配显示器，预览布局后一次平铺。提供中文主界面、系统托盘、全局快捷键和浅色／深色主题。当前版本 v0.5.3，以免安装单文件 EXE 为主要交付方式。

## 开始使用

1. 双击 `artifacts/portable/WindowTiler-0.5.3.exe`，无需安装，也无需另装 .NET。建议把 EXE 放在固定文件夹，方便更新和开机启动。
2. 在左侧勾选窗口，在右侧选择目标显示器。点击“识别显示器”可在屏幕上显示编号。
3. 设置布局、比例和间距。默认把所有勾选窗口平铺到右侧所选屏幕；切换屏幕时保留当前布局，预览始终使用这批已选窗口。
4. 查看预览，点击“平铺到屏幕 N”。执行后将选中窗口显示到前面，每个窗口的执行结果会显示在列表中。
5. 点击“恢复上次位置”撤销最近一次平铺。退出程序后不会保留撤销记录。

布局预览支持拖拽交换：例如四窗口自动均分时，把第 1 格的窗口拖到第 2 格，松手后两个窗口互换位置，第 3、4 格不变。目标格会高亮，窗口列表同步更新；点击平铺后才移动实际窗口。按 Esc、拖到空白处或松手在原格可取消。分组模式只交换当前屏幕的已勾选窗口，不影响其他屏幕或未勾选窗口。

关闭主窗口默认进入托盘。双击托盘图标打开面板，右键菜单可以平铺、恢复或退出。设置中可关闭托盘驻留、启用登录后启动、修改快捷键。

| 默认快捷键 | 操作 |
| --- | --- |
| Ctrl + Alt + Space | 打开操作面板 |
| Ctrl + Alt + Enter | 平铺当前勾选的窗口 |
| Ctrl + Alt + Backspace | 恢复最近一次平铺前的位置 |

v0.4.3 优化多窗口调整速度：多个窗口同时恢复和调整尺寸，已到位时跳过重复操作；固定比例窗口靠拢也同时执行。保留尺寸稳定、实际边界和前置顺序的检查，响应较慢的窗口仍会等待确认。

平铺由按钮、托盘菜单或快捷键手动触发，不会自动接管新打开的窗口。应用重启后需重新勾选窗口；布局配置和模板会保留。

需要一次分配到多个屏幕时，勾选“跨屏分组（按左侧目标屏幕）”。此时左侧显示每行的目标屏幕，可逐个分配，也可用“已勾选 → 当前屏幕”批量分配。右侧配置各屏幕独立布局，点击“按分组平铺”执行。关闭分组模式后，所有勾选窗口统一使用右侧所选屏幕。

平铺完成后按窗口列表顺序整组前置（第一项最靠前），并将铺窗面板移到后面。每个程序的层级调整完成后再处理下一个，最后核对实际顺序，未确认时会提示。之后仍可正常切换其他程序。已有的持续置顶状态保持不变；普通窗口不会因为平铺而持续置顶。若原来就存在持续置顶窗口，仍遵循 Windows 的置顶层级规则。

更新时先从托盘菜单退出旧版，再用新的 EXE 替换旧文件。主题、模板和快捷键保存在 `%LOCALAPPDATA%\WindowTiler\settings.json`，替换 EXE 不会清除这些设置。

构建始终生成带版本号的 EXE，并尝试更新同目录的 `WindowTiler.exe`。若旧版正在运行导致无法覆盖，通用文件名仍是旧版，请退出旧程序后运行带版本号的新文件。

## 外观主题

“设置 → 外观主题”提供三个选项：

- 跟随系统：读取 Windows“设置 → 个性化 → 颜色”中的应用模式，并在系统颜色设置变化时自动更新。
- 浅色（默认）：固定使用白色为主的界面。
- 深色：固定使用深色界面。

选择后立即预览，点击“保存设置”保留选择，关闭设置窗口则恢复原主题。主窗口、下拉列表、输入框、勾选框、滑块、布局预览、编辑器和托盘菜单统一换肤。新配置及未记录主题的旧配置默认使用浅色；已保存的主题选择继续保留。

## 布局

- 自动网格：按窗口数量选择行列，最后一行自动填满；不能整齐均分时，各行中的窗口尺寸可能不同。
- 横向、纵向：在一个方向上均分。
- 主次：主窗口在左、右、上、下；主区域比例为 10%～90%。每块屏幕在列表中排第一的已选窗口作为主窗口。
- 自定义：最多 16 个分区，支持左右拆分、上下拆分、拖动分界线、输入比例和合并上级。模板可新建、编辑、重命名、复制、删除。编辑名称即可重命名。

使用“上移／下移”调整窗口分配顺序。模板保存分区结构与比例；单屏模式切换显示器时沿用当前布局和间距，跨屏分组模式则按显示器分别保存。窗口少于模板分区时，剩余分区空置；超过分区数时阻止执行并提示。相同可用区域、窗口数量和布局参数会得到相同形状的分区；任务栏占用不同会影响实际可用区域。

## 平铺区域与方案

主窗口默认高度为 940，给区域方案和布局预览留出更多空间；启动时仍根据屏幕可用高度适配。

在右侧先选择“平铺区域”，再选择下方的“平铺模式”；全屏时区域下拉框占满整行；划定区域时，区域类型与方案下拉框并排显示。

- **全屏（默认）**：沿用现有逻辑，使用所选显示器的可用范围并避开任务栏。
- **划定区域**：选择保存的区域方案，只在该矩形内计算布局、适配比例及整组靠拢。预览显示整个屏幕，蓝框标出平铺范围。

区域编辑器以灰色背景和外边框标出屏幕总范围，以蓝色标出选中范围，并显示两者尺寸及选中面积占比，浅色／深色主题均适用。

点击“新建区域”，填写名称，在预览中拖出矩形，或点击“在屏幕上框选”直接在目标显示器上拖动；松手完成框选，Esc 取消。可输入距左侧、距顶部、宽度和高度进行像素微调，点击“保存方案”后生效。方案支持编辑、重命名、复制、删除，最多保存 100 个；编辑器取消不会改动原方案。删除方案时，使用它的布局切回全屏。

区域方案与平铺模式相互独立，同一个区域可搭配自动网格、横向、纵向、主次或自定义分区模板。窗口间距仍包含区域外缘的留边，设为 0 时可贴到区域边缘。固定比例窗口在区域内整组居中；区域过小或程序拒绝调整时仍会提示并尝试恢复原位置。

坐标按**显示器可用范围左上角**记录为相对物理像素，不绑定桌面的绝对位置。单屏模式切换目标显示器时保留区域方案；相同可用尺寸的屏幕可复用。跨屏分组模式下，每块显示器可分别选择全屏或不同区域方案。方案在新屏幕上超出边界时会阻止平铺并提示编辑，不会自动缩放或改成全屏。所有方案、区域模式和当前方案选择随设置保存，重启后保留；旧版配置默认全屏。

## 固定宽高比与固定尺寸窗口

阴阳师等窗口化游戏、视频窗口，可以在左侧对应行勾选“保持比例”。程序读取普通状态下的**内容区比例**，标题栏和边框单独占用空间，先适配尺寸，再按原布局的行列关系靠拢，将整组放到屏幕工作区中央。四个同尺寸窗口的 1/2、3/4 之间以及 1/3、2/4 之间都只保留设置的间距，不再各自在原分区中间留出额外空白。间距设为 0 可紧贴，剩余空白放在整组外侧。

整组靠拢用于内置布局，并按每块显示器分别计算。不会拉伸窗口；混合不同尺寸时为避免重叠，会保留尺寸差异所需的空位。自定义模板继续按用户指定的分区适配。

预览会同步显示整组靠拢后的布局。最大化／最小化窗口会先恢复普通状态，再读取比例；尚未读取时预览会标注“恢复普通窗口后读取比例”。拖拽交换会连同该窗口的比例偏好一起交换。刷新保留偏好；当前按窗口在本次运行中保存，重新打开应用后需重新勾选。取消后重新勾选可重新读取当前内容比例。

部分程序会自行纠正外部工具请求的尺寸。普通平铺未匹配分区时，程序会尝试按原内容比例适配，验证实际尺寸和边界后居中，并自动勾选“保持比例”。完全不可缩放、但原尺寸能放入分区的窗口会按允许尺寸居中。分区小于程序最小尺寸、比例无法满足或程序拒绝调整时，会恢复该窗口平铺前的位置并提示，可减少窗口数量或扩大分区后重试。

Windows 没有统一的“固定比例窗口”标记，且有些程序允许外部工具改变比例，因此建议对这类游戏主动勾选“保持比例”。本版使用专用窗口模拟比例、固定尺寸与最小尺寸限制验证，尚未对阴阳师客户端实测；适用于普通窗口模式，独占全屏不在支持范围内。

## 平台和已知边界

- 支持 Windows 10 22H2 / Windows 11，主要提供自带 .NET 10 运行时的 x64 免安装 EXE。
- 使用显示器可用工作区，自动避开任务栏；窗口控制采用物理像素和 Per-Monitor V2 DPI 感知。
- 最小化或最大化的窗口会明确恢复为普通窗口，确认状态、响应和边界稳定后再移动和缩放；从最大化最小化的窗口也适用。恢复超过 2.5 秒未确认时跳过平铺并提示。撤销保存原始位置与显示状态；显示器已断开时，Windows 可能将恢复位置调整到仍连接的屏幕。
- 有最小尺寸、不可缩放、权限较高或响应缓慢的窗口，可能不能严格匹配分区。程序会验证实际边界并提示，保留可撤销的位置。
- 默认按普通权限运行。若需要调整以管理员身份运行的应用，可手动以管理员身份运行铺窗。
- 仅列出当前可见桌面的普通顶层窗口，过滤隐藏、DWM 遮蔽窗口、系统辅助窗口和铺窗自身。游戏独占全屏、其他虚拟桌面的窗口不作为首版支持场景。
- 多屏配置按 Windows 当前设备名称保存。连接方式或拓扑变化后，请刷新并确认目标屏幕，再执行。
- 当前版本通过手动替换 EXE 更新，无在线更新服务。
- EXE 尚未进行代码签名。设置存放在当前用户目录，不与 EXE 放在同一目录。

## 构建

需要 .NET 10 SDK。默认生成自带运行时的单文件免安装 EXE，输出到 `artifacts/portable/WindowTiler-0.5.3.exe`。运行时不依赖其他第三方 NuGet 库。

```powershell
.\scripts\build.ps1 -Dotnet dotnet
```

加 `-SmokeTest` 可在桌面会话中启动专用测试窗口，验证窗口移动、状态恢复、跨屏分组、刷新选择、快捷键注册、主题切换和异常处理。只操作它创建的窗口，不操作用户窗口，不更改 Windows 主题。结果和浅色／深色截图保存到 `artifacts/qa/`。

本工作区构建命令：

```powershell
.\scripts\build.ps1 -Dotnet '..\.window-tiler-tools\dotnet\dotnet.exe' -SmokeTest
```

## 源码结构

安装脚本作为可选发布方式保留；只有显式指定 `-Installer -Iscc <ISCC.exe路径>` 才生成安装包，需要另装 Inno Setup 6。本次 v0.5.3 仅交付免安装 EXE。

| 目录 | 内容 |
| --- | --- |
| `src/WindowTiler.Core` | 独立布局计算、分区树和模板模型 |
| `src/WindowTiler.App` | WPF 界面、Win32 窗口控制、多屏枚举、托盘与快捷键 |
| `tests/WindowTiler.Core.Tests` | 无外部测试框架依赖的布局断言程序 |
| `installer` | Inno Setup 安装脚本与中文界面文本 |
| `scripts` | 构建、测试和发布脚本 |
| `artifacts` | 编译产物、安装包及验证记录，不提交到版本库 |

实际验证结果与待测项目见 `VALIDATION.md`。
